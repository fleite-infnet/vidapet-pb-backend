# VidaPet: Sistema de Agendamento da Clínica Veterinária

**Aluno:** Fernando Leite Rodrigues
**Disciplina:** Projeto de Bloco: Desenvolvimento Back-End [26E4_5] · Instituto Infnet
**Trilha:** C# + ASP.NET Core (.NET 10)

## Estrutura

- `docs/`: documento de requisitos, diagrama de casos de uso (PlantUML) e justificativa do escopo
- `src/`: código-fonte do programa standalone inicial (TP1)

## Uso de IA

Ferramenta utilizada: Claude (Anthropic), via Claude Code, de outubro a novembro de 2026.

De forma geral, o uso de IA seguiu a seguinte metodologia: **tutor de aprendizado**. A IA
apresentou o passo a passo com dicas e exemplos e, depois, revisou o que foi produzido, com
questionamentos de acordo com o contexto de competência exigido pela disciplina.

No programa standalone (`src/`), todo o código foi escrito pelo aluno. A IA explicou conceitos e
sintaxe e revisou cada etapa, sem gerar a solução. Na documentação (`docs/`), a IA redigiu a
primeira versão dos requisitos, dos casos de uso e do diagrama PlantUML a partir do enunciado e das
decisões do aluno, que revisou e aprovou o conteúdo.

Os resultados da IA foram conferidos pelo aluno, compilando e testando o programa e revisando os
documentos.
